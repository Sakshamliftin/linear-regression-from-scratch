# Linear Regression from Scratch using NumPy

This is a simple machine learning project where I implemented linear regression using gradient descent **from scratch**, without using libraries like scikit-learn.

### 🔍 What I Did:
- Created synthetic data with noise using nomal distribution
- Defined the linear model: `y = wx + b`
- Implemented Mean Squared Error (MSE)
- Manually calculated gradients and updated weights using gradient descent
- Visualized the results and convergence of loss

### 🚀 Skills Practiced:
- Gradient descent optimization
- NumPy for vectorized operations
- Data visualization with matplotlib
- Debugging and model tuning

### 📊 Output:
The model successfully learned weights close to the true values despite noisy data.

True values: `w = 2`, `b = 3`  
Learned values: `w ≈ 1.80`, `b ≈ 2.55`
